Simulazione Rete BitTorrent

Come funziona BitTorrent

In BitTorrent i file vengono divisi in piccoli pezzi distribuiti tra gli utenti. Chi possiede il file completo è chiamato seed. Chi sta scaricando è un leecher. Quando un nodo completa il download diventa anch’esso seed.

I peer si scambiano parti del file tra loro, aumentando la velocità e riducendo il carico su un server centrale.
